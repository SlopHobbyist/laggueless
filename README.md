# Multi-Emulator Project

## Goal
The goal is to create a libretro core compatible emulator program. Users find RetroArch confusing, so I will force *my* favorite settings so players can focus on simply playing games. It will also have a large focus on lag/delay, and will have gsync/freesync support.

## Features
- "integer (pixel-perfect) scaling" from bsnes-mt but for all cores
- 'adaptive sync" for gsync/freesync monitors
- simple menu to select games from a folder

## Supported Platforms
- ⭐ Windows x86-64
- Windows x86 (32 bit) (afterthought)
- Ubuntu x86-64 (afterthought)
